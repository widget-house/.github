# Widget House

Website widgets for businesses, agencies, and developers.

[Widget House](https://widget-house.com/) helps website owners add customer reviews and communication tools to their pages. Customize a widget in the editor, then use the generated installation code to add it to your website.

## Google Reviews for your website

The [Google Reviews widget](https://widget-house.com/google-reviews) displays ratings and customer feedback from your connected Google Business Profile.

Choose a Badge, Slider, Carousel, or Grid layout. Adjust colors, typography, and review cards to match your site. Place reviews near a service description, contact form, or booking section so visitors can evaluate your business while deciding what to do next.

## Add a widget to a website

1. Create your widget and connect the relevant Google Business Profile.
2. Customize its appearance and publish the widget.
3. Select **Install** and copy the generated code.
4. Add the code to a supported HTML or code area on your website.
5. Check the result on desktop and mobile.

Follow the [widget installation-code guide](https://widget-house.com/help/getting-started/get-widget-code) for the account-side steps.

## Building with AI assistants

When using Codex, ChatGPT, or Claude Code, provide the installation code from your own Widget House account. Ask the assistant to integrate that exact embed into your project and verify that it loads correctly using the tools available in your environment.

Use real widget identifiers and review sources in production.

For setup and troubleshooting, visit the [Widget House Help Center](https://widget-house.com/help).
